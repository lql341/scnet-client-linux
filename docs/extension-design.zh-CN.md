# 外观设置

本构建新增一个对话框，含三项设置：配色、字号，以及对话框自身的语言。所有效果通过渲染层已有的
CSS 自定义属性实现，不修改厂商代码。

## 实现机制

`scripts/patch-vendor.cjs` 将 `extensions/main.js` 与 `theme.css` 注入渲染层。入口位于头像展开的
账户菜单中，与「设置」「帮助」相邻；该菜单由厂商在每次展开时重新渲染，样式以 `data-v` 属性做
作用域隔离，注入项在运行时复制该属性，而不硬编码哈希。扩展在承载登录壳的 compat 渲染层中不生效，
`window.host` 缺失时同样不生效。

选择结果保存在 `localStorage` 的 `scnet.ext.*` 下。注入的 `<head>` 引导脚本在扩展加载前、且在两个
渲染层中应用已存的配色与字号，因此重启不会先闪默认主题；承载登录壳与作业提交页的 compat 渲染层只
应用配色与字号，不出现菜单项与对话框。

## 配色

共六种。`system` 不改动任何厂商变量；其余五种覆盖表面、文字、边框与强调色变量，并带有跟随厂商
`.dark` 类的深色变体。

| 取值 | 画布 | 强调色 |
| --- | --- | --- |
| `system` | 厂商 | 厂商 |
| `paper` | `#fbfaf7` | `#2f6feb` |
| `sand` | `#faf9f5` | `#d97757` |
| `forest` | `#f7f8f6` | `#2f7d54` |
| `indigo` | `#f8f8fc` | `#4a54c8` |
| `ink` | `#17171a` | `#ffb454` |

渲染层在运行时将 `--color-accent` 与 `--color-accent-hover` 以内联样式写到 `<html>`、`<body>`，
因此这两项声明带 `!important`；其余变量交由层叠处理，厂商仍可自由调整自身取值。

## 字号

`小`、`标准`、`大` 分别对应 0.92、1、1.08 的倍率，通过 `calc()` 作用于渲染层定义的字体与行高变量
（`--font-size-*`、`--line-height-*`、`--chat-font-size`）。备选方案是整页缩放，但
`display.set-client-zoom-factor` 是厂商操作且有自己的持久化，倍率方式则不改变布局比例。

## 语言

默认为中文，与厂商语言无关。`中文` 与 `English` 切换本构建提供的文案，以及两处最显眼位置的一组
固定标签：

| 位置 | 词条 |
| --- | --- |
| 侧栏 | 新建任务 · 消息频道 · 插件 · 自动化 · 高性能计算，分组标题 项目 · 最近，徽标 实名认证 |
| 账户菜单 | 我的资源 · 费用中心 · 设置 · 帮助 · 退出登录 |
| 本对话框 | 菜单项、标题、分组标题、配色与字号名称、脚注 |

替换只遍历 `aside.sidebar-shell` 与 `.account-menu` 的文本节点，仅匹配完全相同的文本，并按节点记录
原文，切回中文时还原。`MutationObserver` 在厂商重新渲染菜单后再次应用。

**范围。** 客户端渲染层没有语言开关——`en.lproj` 覆盖的是 macOS 菜单标签而非应用文本——因此这两处
之外的内容仍为中文：消息正文、提示词、设置页、错误信息。对话框内已注明作用范围；词条集中在
`extensions/main.js` 的一个对象里，厂商改文案时改一行即可。

## 验证

在 Ubuntu 26.04.1 x64/X11 上针对打包产物执行，通过 DevTools 协议驱动并派发真实鼠标事件。

| 检查 | 结果 |
| --- | --- |
| 菜单项 | 「外观」注入在「退出登录」之前，与厂商条目同级，图标尺寸与间距一致 |
| 对话框 | 由菜单项打开，点击遮罩或 Escape 关闭，三个分组正常渲染 |
| 配色 | `forest` 将强调色设为 `#2f7d54` 并重绘侧栏；`ink` 将表面变量切换为深色 |
| 字号 | `大` 时 `--font-size-base` 为 `calc(14px * 1.08)`；`小` 为 `0.92` |
| 语言 | 切到 `English` 后，菜单项、标题、分组、按钮与脚注全部切换 |
| 持久化 | 重启后保留选择，并在首帧前应用 |

未验证：各配色与厂商所有界面元素（图表、代码块、内嵌控制台页面）的组合效果，以及 `ink` 在厂商
自绘对话框中的观感。
